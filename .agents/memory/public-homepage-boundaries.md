---
name: Public homepage boundaries
description: Product positioning and scope constraints for Swayger's public web surface.
---

The public homepage is for signed-out web visitors only. Preserve the signed-in
root Game Day dashboard, native startup, gameplay, auth returns, guest claims,
invites, admin, Discord, and database behavior when changing marketing.

**Why:** The user explicitly limited the redesign to the public experience.

**How to apply:** Treat changes to protected-route rules or gameplay as separate
work, not convenient homepage cleanup. Keep the existing public explainer's
server ownership rather than adding a second app route for the same URL.

Position Swayger as the competitive prediction layer for sports communities.
There are exactly three primary products: Game Day, Fantasy, and 1v1.
NFL, Madden, Discord, and in-venue uses are examples, not additional products.
Use consumer sports language, not sportsbook/wagering language. Never invent
testimonials, traction, customer outcomes, or screenshots. Genuine components
with explicitly labeled example data are distinct from claims of real results.

**Why:** These are the user's locked product and marketing boundaries.

**How to apply:** Preserve the supplied headline and positioning quotations in
future edits; use the active mark rather than old glowing-S assets.
