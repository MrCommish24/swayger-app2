We are doing a focused polish task:

# POLISH TASK — GLOBAL DRAFT DAY RECEIPT
## Shared League-Level Results Artifact

This is NOT a new major phase.

The current Draft Day results screen is working correctly as a PERSONAL RESULTS view.

It shows:

- Draft Day winner
- leaderboard
- each question
- correct answer(s)
- viewer's own pick
- whether that pick was correct
- League Picks link

We are keeping that.

The new goal is to add a separate:

# GLOBAL DRAFT DAY RECEIPT

This should answer:

"What happened in our league?"

rather than:

"How did I personally do?"

The receipt is a SHARED LEAGUE ARTIFACT.

It should be available to every authorized member of the Fantasy league:

- authenticated league members
- valid guest members
- commissioner
- co-commissioner

Its content must be identical regardless of who is viewing it.

Commissioner/co-commissioner should receive the most prominent Share action, but the receipt itself is NOT commissioner-only.

==================================================
1. PRODUCT MODEL
==================================================

We now want three distinct layers:

1. PERSONAL RESULTS
   - existing screen
   - viewer-specific
   - includes "Your Pick"

2. GLOBAL DRAFT DAY RECEIPT
   - league-level
   - available to all authorized league members
   - identical for every viewer
   - winner + standings + correct outcomes
   - designed to be viewed and shared

3. LEAGUE PICKS
   - detailed social receipts
   - who picked what
   - distributions
   - existing Phase 6C behavior

Do NOT merge all three into one giant screen.

==================================================
2. KEEP EXISTING PERSONAL RESULTS
==================================================

Do not remove or redesign the current personalized results screen.

It should continue showing:

- winner
- leaderboard
- correct answer
- viewer's pick
- correct/incorrect state
- League Picks

That experience answers:

"How did I do?"

==================================================

- co-commissioner
