We are beginning:

# PHASE 5.3 — COMMISSIONER WEEKLY WORKFLOW

Current state:

- Draft Day is working
- Week 1 is working
- Week 2+ repeatability is working
- weekly sharing / reminders / Copy Link are working
- participation counts are working
- guest durability/recovery is working
- single-use commissioner recovery has been manually verified
- season standings are derived and working
- weekly settlement/finalization follows the proven Game Day lifecycle

We are now shifting away from identity/infrastructure work.

The product goal is:

# MAKE WEEKLY SWAYGER EASY ENOUGH FOR A COMMISSIONER TO RUN EVERY WEEK

The commissioner should be able to go from:

“Week 2 is over”

to:

“Week 3 is live and shared”

in roughly 2–3 minutes.

This phase is about reducing commissioner effort and making the NEXT ACTION obvious.

Do NOT build notifications, provider integrations, automated scoring, or full season automation.

==================================================
1. PRODUCT PRINCIPLE
==================================================

Swayger Fantasy Season should not feel like another fantasy-admin job.

The commissioner should not have to think:

- What week are we on?
- Where do I create the next one?
- Which questions should I choose?
- Do I need to re-add people?
- How do I share it?
- What do I do after picks come in?

The hub should guide them through the weekly operating loop.

Preferred weekly rhythm:

Finalize Week N

→ Create Week N+1

→ Publish

→ Share

→ Monitor participation

→ Remind

→ Lock Picks

→ Resolve Results

→ Finalize

→ Create Week N+2

==================================================
2. PRIMARY PHASE 5.3 MILESTONE
==================================================

After this phase, I should be able to:

1. Finalize Week 2.
2. Return to Fantasy League Hub.
3. Immediately see:
   NEXT UP
   Week 3 Swayger
   [ Create Week 3 ]
4. Tap Create Week 3.
5. See a high-quality default question set already selected.
6. Optionally:
   - edit selections
   - use last week’s questions
7. Publish Week 3.
8. Return to hub.
9. Immediately see:
   Week 3 is live
   0 / N have played
   [ Share Week 3 ]
10. Share it.
11. Run the same weekly workflow without hunting through screens.

This is the acceptance milestone.
