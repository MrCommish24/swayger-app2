PRODUCT DECISION

Discord V1 will use one modal:

1. Week / Challenge Name
2. Reward
3. Pick Deadline
4. Matchups — multiline
5. Optional Bonus

Matchup syntax parsed by the bot:

Team A | Team B

Bonus syntax parsed by the bot:

Question | Option A | Option B [| Option C...]

The bot will convert those into the existing backend schema.

SECURITY REQUIREMENTS

For bot-authenticated Madden creation:

1. Require valid GAMEDAY_BOT_API_KEY using the existing bot authentication mechanism.

2. Require discord_guild_id in the request body.

3. Require X-Discord-Guild-ID header as well.

4. Require the body discord_guild_id and X-Discord-Guild-ID header to match.

5. Reject missing or mismatched guild IDs.

6. Preserve all existing guild-scoping protections.

7. Store:
   source = "discord"
   discord_guild_id = supplied validated guild ID

8. Accept discord_channel_id if supplied and store it using the existing Discord room metadata convention.

9. Accept discord_user_id if supplied if that field is already part of the existing Discord-created room model.

10. Madden rooms must remain:
    is_private = true

11. Do not weaken the existing human-host authorization path.

12. Do not allow an unauthenticated or ordinary API caller to masquerade as Discord by simply passing Discord metadata.
