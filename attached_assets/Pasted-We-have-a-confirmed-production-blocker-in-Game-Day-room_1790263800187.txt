GDS-CVALJ

→ 404 Room not found

→ 404 Room not found

GET /api/gameday/rooms/GDS-CVALJ/leaderboard
→ 200

- UUID

This makes Discord bot recovery after restart impossible for:
- lock
- resolve
- not-yet-finalized final

because the bot loses its in-memory room UUID cache.

guild + channel + intended action
→ return the appropriate current room

==================================================
CURRENT-ROOM SELECTION RULES
==================================================

Selection must be conservative and deterministic.

For action=lock:
eligible:
- room/card currently open
- same discord_guild_id
- same discord_channel_id
- not finalized

For action=resolve:
eligible:
- locked or partially settled
- same guild/channel
- not finalized

For action=final:
eligible:
- same guild/channel
- not finalized
- all required props settled / eligible to finalize

If exactly one candidate exists:
return it.

If zero:
return 404 / clear no-current-room result.

If more than one plausible candidate exists:
do NOT silently choose based only on global recency.

Return conflict such as:

409

{
  "error": "multiple_active_rooms",
  "rooms": [
    {
      "room_id": "...",
      "room_code": "...",
      "room_name": "...",
      "status": "..."
    }
  ]
}

The bot can then ask the commissioner to specify room_code.

Do not choose the wrong competition.
