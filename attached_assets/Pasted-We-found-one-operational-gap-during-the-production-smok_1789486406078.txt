The existing human archive flow requires an authenticated human owner, so a bot-created Madden room currently has no safe bot-scoped cleanup/archive path.

Do NOT add hard delete.

Extend the existing room archive endpoint/behavior if possible rather than creating a parallel endpoint.

The bot should be able to archive a room only when ALL of the following are true:

1. Request has valid GAMEDAY_BOT_API_KEY.
2. Request includes X-Discord-Guild-ID.
3. The target room has:
   source = "discord"
4. The target room has a stored discord_guild_id.
5. Stored room discord_guild_id exactly matches X-Discord-Guild-ID.
6. The room is not already archived, or archiving again is safely idempotent.
