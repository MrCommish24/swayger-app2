Update the Game Day Swayger NBA prop template/library.

Context:
Game Day Swayger is working well during the NBA playoffs. The current props are good, but we need a deeper and more creative prop library for each lock card:
- Pregame
- Halftime
- 4Q Clutch

Right now, the prop options are too limited, and a few are too subjective or hard to settle.

Goal:
Expand the Game Day prop library to approximately 20 strong, objective prop options per card/phase so the host/admin has more variety when creating each room.

Important:
This should be a prop library expansion, not necessarily a requirement that all 20 props are shown to participants every game.

The host/admin should still be able to select which props are used for that room.

Do not change:
- scoring logic
- card open/lock logic
- settlement logic
- participant flow
- Captain Center
- Discord bot
- SP system
- Game Day room structure
- existing analytics

==================================================
Core Rules For New Props
==================================================

1. Every prop must be objectively settleable.

Avoid subjective language like:
- Who makes the biggest play?
- Who has the most clutch moment?
- Who changes momentum?
- Will either team miss a clutch free throw?
- Who looked better?
- Who had the better half?

2. Remove or retire overly subjective props from the template/library, including:
- “Who makes the biggest play?”
- “Will either team miss a clutch free throw?”
- any similar subjective or debate-heavy props

3. Use clear answer options.

4. Add “Tie” as an answer option for all head-to-head stat comparison props where a tie can realistically happen.

Especially:
- Which star scores more points?
- Which team scores more points in [period]?
- Which player/team has more threes/rebounds/assists/etc. if used

If two numeric outcomes are being compared, include:
- Team A / Player A
- Team B / Player B
- Tie

5. Keep props appropriate to each phase:
- Pregame props should include full-game, first-quarter, first-half, and early-game props.
- Halftime props should be based on what can happen in the second half, third quarter, or full-game outcome from halftime.
- 4Q Clutch props should be about the fourth quarter, final score margin, late-game lead changes, and final stat outcomes that remain interesting late.

6. Prefer props that help leaderboard movement happen throughout the game:
- some settle after Q1
- some settle by halftime
- some settle after Q3
- some settle at final
- some create late-game swing potential

==================================================
Tie Option Requirement
==================================================

Add “Tie” as an answer option to any prop that compares two teams or two players on a numeric stat where a tie is possible.

Examples:
- Which star scores more points?
- Which star scores more points in the 1st half?
- Which star scores more points in the 2nd half?
- Which star scores more points in the 4th quarter?
- Which team scores more points in the 1st quarter?
- Which team scores more points in the 3rd quarter?
- Which team scores more points in the 4th quarter?
- Which team makes more 3-pointers?
- Which team commits more turnovers?
- Which team gets more rebounds?
- Which team makes more free throws?

Do not force a tie option where there cannot realistically be a tie, such as:
- Which team scores first?
- Which team reaches 10 first?
- Who wins the game?

Important:
Settlement UI must allow the host/admin to select Tie when it is an answer option.
Participant UI must show Tie as a selectable option.
Leaderboard/scoring must correctly award points to users who selected Tie if Tie is settled as correct.
