PRODUCT DECISION

For:

source = discord
sport = madden
template_type = weekly_pick_card

we are intentionally removing automatic deadline enforcement for V1.

The commissioner-entered deadline is DISPLAY TEXT ONLY.

The commissioner manually locks the card.

Do not require a real timestamp for this Discord Madden path.

BACKEND REQUIREMENTS

1. Make top-level pick_deadline optional ONLY for Discord-created Madden Weekly Pick Cards.

2. Preserve existing pick_deadline behavior for:
- web-created Madden cards
- NFL
- NBA
- other Game Day formats

3. Accept and persist:

format_config.deadline_display_text

as free-form display text.

Examples:

Sunday 1 PM CST
Sunday at 1
Before kickoff
Week 4 kickoff
Saturday night

Do not parse it.

Do not infer timezone.

Do not convert it to ISO.

Do not derive scheduled_lock_at from it.

4. When pick_deadline is absent for this Discord Madden path:

- scheduled_lock_at must remain null
- deadline_passed must remain false while card is open
- can_edit_picks must remain true while card is open
- no automatic write cutoff should occur

5. Manual commissioner lock remains authoritative.

When card status becomes locked:

- picks are no longer editable
- existing picks remain readable
- receipt/reveal behavior remains unchanged

6. Existing generic lock behavior should be reused.

Do not create a new lock system.

7. Participation/FOMO behavior must still work.

Since Discord Madden V1 no longer creates a bonus prop:

completion = participant has a valid pick for every matchup prop.

The existing participation outbox logic should continue working without modification if possible.

8. Preserve the explicit disabled bonus configuration:

{
  "enabled": false,
  "label": null,
  "answer_options": []
}

Do not create a bonus prop.
