# POLISH TASK — SHAREABLE DRAFT DAY RECEIPT V2
## Receipt Image + Short Link + Receipt-Specific Preview

This is NOT a new major product phase.

We already have:

- Personal Draft Day Results
- Global Draft Day Receipt
- League Picks
- finalized-only receipt access
- authorized league-member viewing
- commissioner/co-commissioner share controls
- Phase 6G multi-correct settlement
- canonical long receipt URL

The current Global Draft Day Receipt works, but real-world sharing exposed three UX problems:

1. The shared receipt has no attached receipt image.
2. The canonical URL is too long for group text.
3. Messaging apps may show a generic Swayger preview card that is not useful enough.

The desired share experience is:

[BEAUTIFUL DRAFT DAY RECEIPT IMAGE]

🏆 Food Pyramid XX — Draft Day Swayger
J Spells wins Week 0 with 20 SP.
The receipts are in 👀
swayger.app/r/7K4M2Q

The share should feel compact, visual, branded, and useful in SMS/RCS/iMessage/group chat.

9. SHORT LINK SECURITY
==================================================

Critical:

The short link is ONLY an alias.

It must NOT bypass existing Fantasy authorization.

Flow:

→ resolves to leagueId + seasonId + receipt destination
→ existing receipt authorization still applies

Do not put:

- auth token
- guest token
- user ID
- member ID
- claim ID
- recovery token

inside the short code.
