- a missing table-level GRANT should normally return 42501 permission denied, not HTTP 200 with [].

We need to directly determine the effective role of the request.

1. ADD A TEMPORARY READ-ONLY DIAGNOSTIC RPC

Create or inspect a safe diagnostic SQL function that returns only:

current_user
session_user
current_setting('request.jwt.claim.role', true)

Do NOT expose secrets or JWT contents.

Example conceptually:

CREATE OR REPLACE FUNCTION public.debug_request_role()
RETURNS json
LANGUAGE sql
SECURITY INVOKER
AS $$
  SELECT json_build_object(
    'current_user', current_user,
    'session_user', session_user,
    'jwt_role', current_setting('request.jwt.claim.role', true)
  );
$$;

Grant EXECUTE only as needed for the diagnostic.

If you do not want to create this permanently, provide the exact SQL and remove it after verification.
