--------------------------------------------------
10. PICK SUBMISSION RULES
--------------------------------------------------

Server must be authoritative.

A Fantasy Draft Day pick can be created/changed only if:

1. room exists
2. room.experience_type='fantasy'
3. room.competition_type='draft_day'
4. participant belongs to room
5. card.status='open'
6. prop belongs to that card
7. selected answer ID exists in that prop's snapshotted answer_options
8. participant/season identity is valid

If card.status='locked':
→ return 409 or appropriate conflict response

If prop doesn't belong to room/card:
→ reject

If answer ID isn't in answer_options:
→ reject

Do not rely on frontend-disabled controls.
