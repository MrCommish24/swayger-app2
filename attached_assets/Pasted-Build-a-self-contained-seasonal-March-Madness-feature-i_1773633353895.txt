==================================================
FEATURE A — LOCKED TAKES
==================================================

Build a Locked Takes area with one-time tournament picks.

MVP Locked Takes:
1. Champion Pick
   - one champion pick per account
   - locks at tournament start
   - cannot be edited after lock

2. Final Four Picks
   - one Final Four submission per account
   - user selects 4 teams
   - locks at tournament start
   - cannot be edited after lock

3. Elite Eight Picks
   - include only if practical after the first two are working well
   - treat as secondary to Champion + Final Four
   - if included, one Elite Eight submission per account
   - also locks at tournament start

Implementation notes:
- enforce one submission per user/account for each locked take type
- enforce lock server-side, not just in the UI
- users should be able to view their locked takes after submission
- users should be able to generate share cards for these picks immediately after locking them

==================================================
FEATURE B — ROUND-BASED QUICK PICKS
==================================================

Build round-based quick picks, not weekly picks.

Reason:
March Madness works best in round windows, not generic weeks.

Each round should have a set of quick pick props users can make.

MVP quick pick types:

1. Upset Picks
Definition of upset for MVP:
- lower seed beats higher seed

Round-based upset pick limits:
- Round of 64: up to 3 upset picks
- Round of 32: up to 2 upset picks
- Sweet 16: up to 1 upset pick
- Elite 8: up to 1 upset pick
- Final Four: optional only if practical
- Championship: not needed as upset pick type

2. Biggest Blowout
For a given round, user picks which matchup/team will produce the largest margin of victory

3. Highest-Scoring Game
For a given round, user picks which game will have the most combined points

If needed, prioritize implementation in this order:
1. Upset Picks
2. Highest-Scoring Game
3. Biggest Blowout

Do NOT add too many prop categories in MVP.
Keep it simple and understandable.

==================================================
SCORING MODEL
==================================================

Keep scoring simple, transparent, and easy to explain.

Recommended MVP scoring:

Locked Takes:
- correct Champion pick = 10 points
- each correct Final Four team = 5 points
- each correct Elite Eight team = 2 or 3 points only if Elite Eight is included

Quick Picks:
- each correct upset pick = 3 points
- correct Biggest Blowout pick = 3 points
- correct Highest-Scoring Game pick = 3 points

If needed, skip bonuses in MVP.

Important requirements:
- scoring must be recomputable
- scoring must be idempotent
- no double counting
- admin must be able to re-run scoring safely
