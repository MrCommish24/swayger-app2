We tested the NFL Sunday Slate room and fixed team/game scoping successfully.

Current status:
- Early team props now only show Early Slate teams.
- Late team props now only show Late Slate teams.
- Early/Late game props are correctly scoped.
- Sunday Night team props correctly use only Sunday Night teams.
- Discord posting flow is already live-tested and passing.

For Early Slate player props:

- Prefer `early_qb_candidates` for Early Slate QB passing yards.
- Prefer `early_rb_candidates` for Early Slate RB rushing yards.
- Prefer `early_receiver_candidates` for Early Slate WR/TE receiving yards.
- If the scoped list is missing/empty, fall back to the existing global list for backward compatibility.

For Late Slate player props:

- Prefer `late_qb_candidates` for Late Slate QB passing yards.
- Prefer `late_rb_candidates` for Late Slate RB rushing yards.
- Prefer `late_receiver_candidates` for Late Slate WR/TE receiving yards.
- If the scoped list is missing/empty, fall back to the existing global list for backward compatibility.

For Sunday Night:

- Do not add player props unless they already exist.
- Existing Sunday Night team props should continue using only `sunday_night_teams`.
