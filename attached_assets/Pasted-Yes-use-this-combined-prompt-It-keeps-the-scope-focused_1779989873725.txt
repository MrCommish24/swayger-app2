These users need the room itself to explain the Game Day cadence and tell them what is open now, what is coming next, and when to check back.

Also, users have said pick windows can feel rushed or easy to miss. A simple manual countdown notice can help participants know when a card is about to open or lock.

This should be a lightweight communication/clarity improvement only.

PART 1 — Improve Participant Room Cadence

Goal:
Make the participant room clearly show:

- what pick windows exist
- what is open now
- what is locked
- what is coming next
- when users should check back
- that users can still participate in future windows even if they missed an earlier one

Add a “Game Day Timeline” section near the top of the participant room.

The timeline should show:

1. Pregame Picks
2. Halftime Picks
3. 4Q Clutch Picks
4. Final Receipts

Each phase should show a clear status:

- Open Now
- Locked
- Coming Up
- Receipts Ready
- Finalized

Use the existing card/room state to determine these statuses.

PART 2 — Add “Next Pick Window” Callout

Add a prominent “Next Pick Window” or “What’s Next” callout near the top of the participant room.

Suggested copy by state:

If Pregame is open:
“Pregame Picks are open now. Lock in before tipoff.”

If Pregame is locked and Halftime is not open yet:
“Next up: Halftime Picks. Check back at halftime to make your second-half calls.”

If Halftime is open:
“Halftime Picks are live. Make your second-half calls now.”

If Halftime is locked and 4Q is not open yet:
“Next up: 4Q Clutch Picks. Check back near the start of the 4th quarter.”

If 4Q is open:
“4Q Clutch Picks are live. Last window to move up before receipts drop.”

If no picks are open:
“No picks are open right now. Check the timeline below to see what’s coming next.”

If room is finalized:
“Receipts are in. View final standings.”

If user missed Pregame:
“Pregame Picks are locked, but you can still join Halftime and 4Q picks.”

If user missed Halftime but 4Q remains:
“Halftime Picks are locked, but 4Q Clutch Picks are still coming.”

Do not make the room feel broken just because no card is open.

Avoid only saying:
“No picks are open right now.”

Always provide a next-step explanation.

PART 3 — Lightweight Manual Countdown Notices

Goal:
Allow the admin/host to start simple 5-minute or 10-minute countdown notices that appear in the participant room and Captain Center.

This is a communication aid only.

Countdowns should NOT automatically open or lock cards.

Add a “Participant Countdown Notice” section to the Game Day Host Panel.

Controls:

1. Select phase:

- Pregame
- Halftime
- 4Q

2. Select notice type:

- Opens Soon
- Locks Soon

3. Select duration:

- 5 minutes
- 10 minutes

4. Buttons:

- Start Countdown
- Clear Countdown

Suggested persisted countdown state:

- countdown_phase
- countdown_type: opens_soon | locks_soon
- countdown_ends_at
- countdown_started_at
- countdown_started_by_user_id if available

Use the simplest persistence approach consistent with the current app.

If a DB migration is needed, provide it clearly and do not proceed without noting it.

PART 4 — Participant Room Countdown Display

If a countdown is active, show a prominent countdown banner near the top of the participant Game Day room.

The countdown should visually update as time passes.

Suggested copy:

For Halftime Opens Soon:
“Halftime Picks open soon.
Expected in ~5:00.
Stay close — second-half picks are coming.”

For Halftime Locks Soon:
“Halftime Picks lock soon.
5:00 left to submit your picks.”

For 4Q Opens Soon:
“4Q Clutch Picks open soon.
Last window to move up before receipts drop.”

For 4Q Locks Soon:
“4Q Picks lock soon.
Get your picks in before the window closes.”

For Pregame Locks Soon:
“Pregame Picks lock soon.
Get your picks in before tipoff.”

Important:
If countdown reaches zero, do not automatically open or lock a card.

After expiration, show a soft message for a short grace period such as:
“Window update expected now. Check the room.”

Or hide the countdown after expiration.

Use language like “expected” or “coming soon” for open notices so users do not assume the card will automatically open exactly when the timer hits zero.
