Core V1 workflow:

Commissioner:
1. Signs in as an authorized Game Day host.
2. Creates a private Madden Weekly Pick Card.
3. Enters:
   - Week/challenge name
   - Reward text
   - Pick deadline
   - Minimum matchup count
   - 3–7 matchups
   - Team A / Team B for each matchup
   - Optional line/spread display text
   - Optional bonus question
4. Gets a private room link and copy-ready Discord message.
5. Posts that link manually into the Madden Discord server.
6. Locks the card at the deadline.
7. Settles matchup results manually.
8. Finalizes and manually awards the Madden reward.

Participant:
1. Opens the Swayger link from Discord.
2. Joins as guest or signed-in user.
3. Picks one side for each matchup.
4. Can edit picks until lock.
5. Sees results/leaderboard after settlement.

Architecture:
- Reuse existing Game Day rooms, cards, props, participants, picks, lock lifecycle, manual settlement, leaderboard, finalization, private links, and Continue Playing re-entry.
- One Madden Weekly Pick Card should be one private Game Day room.
- Use one aggregate card, likely pregame phase.
- Each matchup should create one two-choice prop.
- Keep answer options as strings.
- Put Madden-specific metadata in validated format_config.
- Do not use fake team/star values if the existing room shape expects two teams/stars; use format-aware display instead.
