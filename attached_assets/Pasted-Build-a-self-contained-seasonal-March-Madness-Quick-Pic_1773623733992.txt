FEATURE 1 — LOCKED TOURNAMENT TAKES
==================================================

Create a section for “Locked Takes” inside the March Madness module.

These are one-time picks that lock and cannot be changed after the lock deadline.

MVP locked takes:
1. Final Four Picks
   - each user gets one Final Four submission per account
   - user selects 4 teams
   - locks at the defined tournament lock time

2. Champion Pick
   - each user gets one champion pick per account
   - locks at the defined tournament lock time

Implementation notes:
- one submission per user/account for each locked take type
- users can view their locked take after submission
- users cannot edit after lock
- server-side lock enforcement is required
- if display name / alias is already part of the profile system, reuse it for receipts and leaderboard

==================================================
FEATURE 2 — ROUND-BASED QUICK PICK PROPS
==================================================

Create recurring quick pick props that users can make during the tournament.

These should be lightweight and designed to get people back into the app.

Primary MVP quick pick type:
Upset Picks

Definition of upset for MVP:
- lower seed beats higher seed

Round-based limits:
- Round of 64: user gets up to 3 upset picks
- Round of 32: user gets up to 2 upset picks
- Sweet 16: user gets up to 1 upset pick
- Elite 8: user gets up to 1 upset pick
- Final Four: optional, only include if it makes sense
- Championship: probably not needed as upset mechanic

System requirements:
- track upset picks by user and round
- prevent users from exceeding the pick limit for that round
- lock picks for each matchup at game start, or lock the round when appropriate
- use server-side validation for locks and limits

Additional quick pick props:
If practical, add one featured “Game of the Day” style quick pick in early rounds.
But do NOT overcomplicate the MVP.

==================================================
SUGGESTED SCORING MODEL
==================================================

Keep scoring simple and transparent.

Recommended MVP scoring:
- each correct Final Four team = 5 points
- correct Champion pick = 10 points
- each correct upset pick = 3 points
- optional bonus if all Final Four teams are correct
- optional bonus if champion was also one of the Final Four picks

If needed, keep bonuses out of MVP and just use base points.

Important:
- scoring must be easy to explain
- scoring must be recomputable
- scoring must not double count
- admin must be able to re-run scoring safely

FEATURE 6 — EMAIL REMINDER SYSTEM
==================================================

Build a practical reminder framework for this feature.

The app only has email notifications.
We want useful reminders without spamming users.

Build reminder logic and admin-configurable cadence based on:
- tournament round / date
- whether the user has made their locked takes yet
- whether the user has made available upset picks for the current round
- whether the user has been active recently in the app

Recommended reminder behavior:

- suppress reminders if user has been recently active

- keep cadence lightweight

Important:

2. the ability to trigger sends manually or semi-manually
