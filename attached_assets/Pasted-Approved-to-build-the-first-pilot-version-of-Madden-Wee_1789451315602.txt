Approved to build the first pilot version of Madden Weekly Pick Card as an additive Game Day format.

Product decision:
Do not call this Swayger Parlay in the product UI. Use:

- User-facing format: Madden Weekly Pick Card
- Commissioner-facing label: Commissioner Pick Card
- Internal template_type: weekly_pick_card
- sport: madden

Goal:
Let a commissioner recreate the weekly Madden Discord pick-card/parlay behavior inside Swayger with a private room, matchup picks, manual settlement, and copy-ready Discord messaging.

Do not build Neon integration.
Do not build Madden API integration.
Do not build odds/spread sourcing.
Do not build sportsbook/parlay language.
Do not build automatic Discord posting.
Do not build subscriptions.
Do not build automatic trait upgrades.
Do not build exact numeric closest-to-total tiebreaking yet.
Do not modify NFL Sunday Slate, NFL Single Game, NBA Game Day, Fantasy, or Discord subscription behavior.

V1 decisions:
1. Bonus question is optional and manually settled only.
2. No exact numeric closest-to-total tiebreaker in V1.
3. Winner can be commissioner-selected/confirmed after settlement.
4. Creation is limited to existing Game Day hosts/authorized creators for the pilot.
5. Minimum matchup rule is enforced at creation.
6. Reward text is display-only.

Build scope:

A. Additive format foundation
- Support sport = madden.
- Support template_type = weekly_pick_card.
- Add validated format_config for:
  - week_label
  - reward_text
  - minimum_matchups
  - scoring_mode
  - bonus metadata if enabled
- Use one private Game Day room.
- Use one aggregate pregame card.
- Each commissioner-entered matchup creates one prop with exactly two answer options.
- Use existing pick submission, guest/auth joins, card lock, manual prop settlement, leaderboard, and finalization behavior.

B. Commissioner creation flow
Add a creation UI for authorized Game Day hosts:

Label:
Create Madden Weekly Pick Card

Fields:
- Challenge/week name
- Reward text
- Minimum matchup count
- Pick deadline
- Matchup editor:
  - Team A
  - Team B
  - Optional line/spread display text
- Optional bonus toggle:
  - Bonus label/question
  - Bonus answer options or manually settled choice
- Create private room button

After creation, show:
- Private participant link
- Copy-ready Discord message
- Host/admin link if applicable

C. Participant UI
Reuse the current Game Day room screen, with format-aware display:
- Show Madden Weekly Pick Card label.
- Show week label.
- Show reward text.
- Show deadline.
- Show matchup questions.
- Show optional line text if provided.
- Make clear picks can be edited until lock.
- Make clear reward is administered by the commissioner.

D. Host UI
Reuse existing host controls with format-aware labels:
- Open/lock the weekly card.
- Manually settle matchup props.
- Settle optional bonus prop if enabled.
- Finalize room.
- Display reward text.
- If feasible, add commissioner-selected winner confirmation as a V1 manual action. If this is larger than expected, stop and report.

E. Data/model rules
- Do not use fake team/star values for Madden rooms.
- Matchups live as props.
- Format metadata lives in validated format_config.
- Keep answer options as strings.
- Do not introduce object-shaped answer options unless all shared participant/host/reveal paths are updated.
- Public discovery should not expose private rooms.
- Existing Game Day Hub Continue Playing should work for authenticated participants.
