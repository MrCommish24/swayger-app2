PART 1 — Add consistent properties to existing PostHog events
==================================================

For every Game Day PostHog event, include these properties where available:

Required common properties:
- room_id
- room_code
- room_source: app | discord | unknown
- entry_source: discord | qr | text | direct_link | app | unknown
- room_status

Important:
Use `room_source` for how the room was created.
Use `entry_source` for how the participant entered the room.

Examples:
- A room created by the Discord bot should have room_source = "discord".
- A user clicking a Discord-posted link should have entry_source = "discord" if that is detectable.
- A QR link with ?src=qr should have entry_source = "qr".
- A normal web/app-created room should have room_source = "app".

Do not rename existing events.

If any source is unknown, use "unknown" instead of leaving it blank.

PART 7 — QR / source query param handling
==================================================

If the URL contains any of the following:
- ?src=qr
- ?src=discord
- ?source=qr
- ?source=discord
- ?utm_source=discord
- ?utm_source=qr

Map that into entry_source.

Examples:
- ?src=qr → entry_source = "qr"
- ?src=discord → entry_source = "discord"
- ?utm_source=discord → entry_source = "discord"

If no source param exists, attempt to infer:
- referrer includes discord → entry_source = "discord"
- otherwise use direct_link or unknown

Do not build a QR feature in this task. Just make sure source params are captured if present.
