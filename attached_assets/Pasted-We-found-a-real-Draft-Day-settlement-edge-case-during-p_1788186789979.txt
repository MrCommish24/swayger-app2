# PHASE 6G — MULTIPLE CORRECT ANSWERS
## Settlement + Scoring Enhancement

This is NOT a new product phase.

This is a targeted settlement/scoring correction discovered from a real Draft Day board.

Current limitation:
A Swayger prop can currently be settled with only ONE correct answer.

Real Draft Day examples showed that is insufficient:

Example 1:
"Who drafts the most running backs?"

Actual result:
- Grim Reaper
- Team Jasand Shootaw
- Mr Big aka Clown Maker

All three tied for the most RBs.

Example 2:
"Who drafts three or more quarterbacks?"

Actual result:
- Appetite 4 Destruction
- Hilson

Both satisfy the condition.

A generic "Tie" answer is NOT the right solution.

The correct product model is:

# A PROP MAY HAVE ONE OR MORE CORRECT ANSWER IDs.

If a participant's selected answer is contained in the correct-answer set:
→ correct

Otherwise:
→ incorrect

==================================================
3. DO NOT ADD "TIE" AS A GENERIC ANSWER
==================================================

Do NOT automatically add:

Tie

to answer_options.

Why:

"Who drafts three or more quarterbacks?"
is not a tie question.

Multiple teams can independently satisfy the condition.

For tied "most X" questions, selecting all actual tied teams is more accurate than selecting "Tie."

No generic tie workaround.

11. SCORING
==================================================

Critical.

Current logic likely does:

selected_answer === correct_answer

Replace/normalize to:

correctAnswers.includes(selected_answer)

Participant still earns the prop's full point_value.

Do NOT split points among tied correct answers.

Example:

20-point prop.

A, B, C are all correct.

User picked B.

User receives:
20 points

NOT:
6.67 points
