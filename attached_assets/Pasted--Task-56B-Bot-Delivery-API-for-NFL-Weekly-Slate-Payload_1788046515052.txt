# Task #56B — Bot Delivery API for NFL Weekly Slate Payloads

Task #56 / Task #54A is complete, but there is no dedicated bot endpoint to fetch post-ready NFL weekly slate payloads or mark instances as posted/failed.

Do not have the Discord bot query Supabase directly.
Do not expose the Supabase service-role key to the Discord bot.
Do not require the bot to use MM_ADMIN_TOKEN.

Use the existing GAMEDAY_BOT_API_KEY authentication pattern used by other Discord bot/Game Day routes.

## Objective

Add bot-authenticated API endpoints so the Discord bot can:

1. Fetch post-ready NFL weekly slate room instances.
2. Mark an instance as posted after Discord confirms the message was sent.
3. Mark an instance as failed if Discord posting fails.

This task should not post to Discord.
This task should not create rooms.
This task should not publish master slates.
This task should not settle, finalize, create receipts, schedule reminders, assign rewards, or call external sports APIs.

## Endpoint 1 — Fetch post-ready instances

Add:

GET /api/gameday/bot/nfl-weekly-slate-room-instances/post-ready

Auth:

GAMEDAY_BOT_API_KEY

Query params:

- master_slate_id optional
- discord_guild_id optional
- limit optional, default 50, max 100

Behavior:

- Return only instances where status = post_ready
- Order by created_at asc
- Include:
  - instance id
  - master_slate_id
  - gameday_room_id
  - room_code
  - room_url
  - discord_guild_id
  - discord_guild_name
  - discord_channel_id
  - discord_channel_name
  - receipt_channel_id
  - receipt_channel_name
  - reward_text
  - post_payload
  - created_at
  - updated_at

Response shape:

{

  "count": 1,

## Endpoint 2 — Mark posted

Add:

POST /api/gameday/bot/nfl-weekly-slate-room-instances/:instanceId/posted

Auth:

GAMEDAY_BOT_API_KEY

Payload:

{
  "discord_message_id": "123456789012345678"
}

Behavior:

- Only update rows where:
  - id = :instanceId
  - status = post_ready
- Set:
  - status = posted
  - discord_message_id
  - posted_at = now()
  - updated_at = now()
- Return updated instance.
- If row is missing or not post_ready, return a clear conflict response.
- Do not overwrite an already-posted message ID.

## Endpoint 3 — Mark failed

Add:

POST /api/gameday/bot/nfl-weekly-slate-room-instances/:instanceId/failed

Auth:

GAMEDAY_BOT_API_KEY

Payload:

{
  "post_error": "Missing Discord channel permission"
}

Behavior:

- Only update rows where:
  - id = :instanceId
  - status = post_ready
- Set:
  - status = failed
  - post_error
  - updated_at = now()
- Return updated instance.
- If row is missing or not post_ready, return a clear conflict response.
- Bound/sanitize post_error to a reasonable length.
